# Схема виконання плану РМУ КДПУ

Публічна схема першої ступені плану Ради молодих учених КДПУ — Школи молодого науковця.
Сторінка: https://astrafreeman.github.io/rmu-skhema/

Точка на схемі — операція: один контракт, одна людина; колір точки — стан виконання.
Схему згенеровано автоматично з робочого плану Ради, тож вносити правки сюди не треба: їх перезапише наступне оновлення.
